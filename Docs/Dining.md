# 主食・汁・副食の取餐と食膳 — Agriculture実装

更新：2026-10-29。Agriculture PR #281の通常ロード用実装。実体は`Source/AMJAgriculture.Dining/Dining.cs`と`Assemblies/AMJAgriculture.Dining.dll`。検証専用の`Tools/Research/DailyMenuEvaluation/PlatePrototype.cs`とは別の製品コードである。

## 実際の動作

- 必須依存はMedieval Overhaul・Harmony・Daily Menu。Culture・Project・Pickle・Quickstartsはプレイ時に不要。
- 調理した料理をDaily Menuの餐台へ備蓄する。空腹になったPawnが、主食を基礎に、用意できる汁と副食を各1品取り分ける。
- 分量は主食：汁：副食の重み3：1：1で、空腹分の栄養を配分する。汁がなければ主食：副食3：1、主食だけなら主食で満たす。数値は最初の実装値で、長期の食品経済・効果バランスの最終承認ではない。
- 一つの`AMJA_MealPlate`に元の小分け食品を保持し、通常のIngest動作を1回行う。各料理の材料、腐敗進行、食事効果は保持する。膳を追加の料理として記録せず、栄養やDaily Menuの食事記録を二重に増やさない。
- 取り分け途中で作業が中断された場合は、既に取った食物を入れた膳を足元へ残す。食べきれない分は膳に残る。膳と中の食品をScribeで保存する。
- Daily Menuが元から認める病人・囚人等の代理配膳条件を維持し、取餐先をAgricultureの膳へ接続する。自力で食べられない相手には一膳を食べさせ、自力喫食できる相手には渡す。
- 汎用の「簡単な食事」単品・一括の新規調理Billを停止する。旧食事ThingDef・RecipeDefは保存し、既存の食事やセーブ参照を削除しない。主食が餐台にない場合の既存食料への緊急フォールバックは残す。

## 接続済みの料理

| 役割 | 通常ロードでの分類 |
|---|---|
| 主食 | Agricultureの共通飯・共通粥・粉食・白飯・白粥・餺飥・蕎麦掻き・雑穀団子・大麦粉粥の9食品 |
| 汁 | MOの骨スープ・キノコスープ |
| 副食 | MOの串焼き・焼き卵・vegetable pot |

分類は`Patches/DailyMenu_MealRoles.xml`の`MealRoleExtension`に置く。今後Agricultureで採用する料理も同じ拡張で接続できる。既存MO料理の利用は、その作物の歴史的採否・新たな栽培許可・停止済みBillの復活を意味しない。新しい歴史料理・調味料・栽培作物を本機能のためだけに追加していない。

## 設置・利用

1. Harmony、MOとその前提、Daily Menu、Agricultureを読み込む。依存宣言によりAgricultureはDaily Menuより後。
2. 通常の調理BillでAgricultureの飯・粥などを作る。汁・副食は既存のMOの設備とRecipeを利用する。
3. Daily Menuの餐台を料理別に設置・指定し、完成料理を補充する。少なくとも主食の餐台を1台用意する。
4. 空腹時の取餐は自動。各Pawnの食事時刻を揃える必要はない。

Daily Menuの自動生産計画は別機能で、今回の実喫食検証はOFFで実施した。任意の料理を自動で歴史的な献立に分類するUIや、料理人を待つ食前調理機構は追加していない。

## Daily Menuの配布物を変更しない互換処理

0.3.7のSupply補助DLLには、内部ヘルパー`Prepare`がHarmony予約名と衝突する2クラスがある。Agricultureは標準の起動クラス実行箇所で、このSupply起動クラスだけを置き換え、実際のPrefix等を個別に登録する。ヘルパーを準備コールバックとして実行せず、実処理からの正常な呼出は残す。問題のヘルパーがない将来版では標準の起動へ戻る。

Daily Menu本体・補助DLLの交換や改変は不要。元のWorkshopファイルを修正しない。餐台と飲物台のMass欠落は独立XMLパッチで補う（木材40／60個×質量0.4を基準に16／24）。重量が既に明示された版を対象に上書きしない。

## 検証と限界

### Cheat Menu併用時の受け入れ判定（2026-10-29追補）

Cheat Menuの`Cheat_Menu.CompCheatStatOffsets`が通常の簡単な食事にも付与され、Daily Menuが小分け非対応と判定して餐台のフィルタを全解除する問題に対応。作者指示により、Agricultureの連携DLL内でこのCompだけを`FoodState.Unsupported`の検査対象から除外する。検査用の一時的なThingDefコピーを用い、元のDef・食品Comp・保存値は変更せず、他の非対応判定は維持する。Cheat Menuへの新たな依存は追加しない。日本語化Modには実装しない。

**受け入れ判定だけの暫定対応であり、小分け時の個体別能力値変更の引き継ぎは追加していない。** 再起動後に適用される。下記の既存実喫食検証はこの変更前のDLLに対する証拠であり、Cheat Menu併用時の補充・小分けはゲーム内未検証。変更後DLLは導入済みRimWorld・Harmony・Daily Menu参照でビルド確認。

[実行結果](ValidationEvidence/Dining-20261029/result.json)と同フォルダーの完全ログを参照。隔離WSL2＋Xvfb、RimWorld 1.6.4871 rev600、実MO＋Daily Menu＋Agriculture。**製品DLLを通常ロード**し、Pickle等は試験の起動・確認だけに使用した。
